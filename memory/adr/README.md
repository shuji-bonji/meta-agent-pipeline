# Architecture Decision Records

> アーキテクチャ判断の記録。実証で得た知見が ADR に昇格すると、以降の Sub-agent はこの判断を前提に動作する。

## フォーマット

ファイル名: `NNN-short-title.md` (NNN は連番、3 桁)

```markdown
# ADR-NNN: <タイトル>

**Status**: proposed | accepted | superseded by ADR-MMM
**Date**: YYYY-MM-DD
**Context**: <なぜこの決定が必要になったか>
**Decision**: <何を決めたか>
**Consequences**: <この決定の帰結 (good / bad / neutral)>
**Related**: <関連 ADR / Issue / experiment>
```
